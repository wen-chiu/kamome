# Visual reviews

One file per review, named `YYYY-MM-DD-<subject>.md`, in the format `DESIGNER.md`
specifies.

**A review that lands anything under Blocking also gets one line in
`HANDOFF.md`** naming it and pointing here. A finding that exists only in a
conversation has not been delivered — the same rule `PO.md` applies to
product findings.

Reviews judge renders. The renders themselves stay outside this repository
(`~/Kamome-films/`), per §0; cite them by path and frame, never by copying one in.
