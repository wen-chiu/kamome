# Visual reviews

One file per review, named `YYYY-MM-DD-<subject>.md`, in the format `CHARTER.md` §7
specifies.

**A review that lands anything under Blocking also gets a `desk` issue**
naming it and pointing here. A finding that exists only in a
conversation has not been delivered — the same rule `CLAUDE.md` applies to
every finding.

Reviews judge renders. The renders themselves stay outside this repository
(`~/Kamome-films/`), per §0; cite them by path and frame, never by copying one in.
